"# OpenWebUI LangGraph Agent

A lightweight Open WebUI-compatible chat backend powered by a local LangGraph agent and Ollama model. The project exposes a FastAPI-compatible API that Open WebUI can call, while the agent can use tools like web search, calculator, current time, and note saving.

## Features

- OpenAI-compatible chat endpoint for Open WebUI
- LangGraph-based agent orchestration
- Local Ollama LLM integration
- Tool calling with:
  - web search
  - calculator
  - current time
  - save note
  - list notes
- Streaming responses for real-time chat UI updates

## Project structure

- `agent.py` – LangGraph agent and tools
- `server.py` – FastAPI compatibility layer for Open WebUI
- `notes/` – saved note files generated by the agent
- `README.md` – project documentation

## Requirements

- Python 3.10+
- Ollama installed and running locally
- A model pulled into Ollama, such as `llama3.1`

## Setup

1. Open a terminal in the project folder.
2. Activate the virtual environment:

```powershell
.\venv\Scripts\Activate.ps1
```

3. Start Ollama:

```powershell
ollama serve
```

4. Pull the model:

```powershell
ollama pull llama3.1
```

5. Start the API server:

```powershell
python -m uvicorn server:app --host 0.0.0.0 --port 8000
```

## Run the agent directly

```powershell
python agent.py
```

This runs a quick built-in example query without requiring Open WebUI.

## Open WebUI configuration

Use the Open WebUI connection settings pointing to this backend API:

- Base URL: `http://localhost:8000`
- API path: `/v1/chat/completions`

The API also exposes model metadata at:

- `/v1/models`

## Notes

The agent uses a local notes folder to save generated summaries and outputs. Files are stored under `notes/` as `.txt` documents.
